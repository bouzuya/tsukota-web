# tsukota-web フロントエンド

React + Vite によるフロントエンドアプリケーション

## 技術スタック

- **React** 19.2 - UI ライブラリ
- **TypeScript** - 型安全性
- **Vite** 7.3 - ビルドツール・開発サーバー
- **Tailwind CSS** 3.4 - CSS フレームワーク
- **jotai** 2.16 - 状態管理
- **React Router** 7.12 - ルーティング

## 開発

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動 (http://localhost:5173)
npm run dev

# 本番ビルド
npm run build

# ビルドのプレビュー
npm preview

# Lint
npm run lint
```
