# 089

- domain crate の mod 構成を見直します。以下の構成に変更してください

```
aggregates/
    account/
        commands.rs
        events.rs
        value_objects.rs …… account 固有の Value Object
    account.rs
value_objects/ …… *Id など account 固有でない Value Object
    account_id.rs
    ...
aggregates.rs
value_objects.rs
```

- 他の crate からの参照方法が変わらないようにしてください
    - 必要なら re-export してください
- aggregates.rs から aggregates/*.rs のようなひとつ下の階層の mod を参照する際は次のように `self::` を明示し、 `*` の使用を避けて、すべて展開してください

```
mod account;

pub use self::account::Account;
pub use self::account::AccountEventCommonProps;
```
