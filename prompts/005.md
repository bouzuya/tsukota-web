# 005

tsukota-web は <https://github.com/bouzuya/tsukota> の web 版であり、それを踏襲してイベントソーシングを採用します。

集約 (イベントストリーム) の単位は「アカウント」のみです。分類や取引はすべてアカウントの一部として扱います。イベントの一覧は <https://github.com/bouzuya/tsukota/blob/master/packages/account-events/src/account-events.ts> です。

「ユーザー」についてはイベントソーシングを使用していません。

スキーマ定義は <https://github.com/bouzuya/tsukota/blob/master/packages/schema/src/schema.ts> です。
