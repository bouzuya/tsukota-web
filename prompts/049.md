# 049

- UseCase の戻り値は application crate で定義されたものか primitive な値にしてください
    - 例: `AccountId` -> `String`
- 入力が `*Request` になっているので、出力は `*Response` にしてください
    - 例: `pub async fn execute(&self, user_id: &UserId, request: CreateAccountRequest) -> Result<CreateAccountResponse, ApplicationError>`
    - 例: `pub struct CreateAccountResponse { account_id: String; }`
