# 086

- backend/ に `create_custom_token` を追加します
- 文字列型の `device_id` と `device_secret` をリクエストボディとして受け取ります
- Firestore の `/devices/{device_id}` ドキュメントを読み込みます
- ドキュメントが存在し、ドキュメントの `encryptedSecret` フィールドと `device_secret` を bcrypt の hash が一致すれば、 ドキュメントの uid フィールドを、一致しなければ新規の uuid v4 を uid として得ます
- Firebase Auth で uid に対してのカスタムトークンを生成します 
- Firestore の `/devices/{device_id}` ドキュメントを作成または更新します
  - id フィールドに device_id
  - encryptedSecret フィールドに device_secret をコストファクター 10 で hash したもの
  - uid フィールドに uid
  - 更新するので
    - device_secret を誤ってリクエストすると、それまでの user (uid) を失うことになります
    - device の存在確認を外部からは不可能にします
    - 代わりに id が分かれば破壊されるリスクがあります
- Firestore の `/users/{uid}` ドキュメントをなければ作成する
  - id フィールドに uid
  - account_ids フィールドに空
- レスポンスとしては `custom_token` フィールドに生成した Firebase Auth のカスタムトークンを設定して返す
