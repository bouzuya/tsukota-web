# 004

不明事項についての回答は次の通りです。これらを `docs/SPEC.md` に反映してください。

## 認証・JWT

1. **JWT 有効期限**: JWT トークンの有効期限は？リフレッシュトークンは使用するか？

15 分。リフレッシュトークンを使用します。

## API 仕様

2. **ページング方式**: 取引一覧の次ページ取得方法は？（offset ベース / cursor ベース？）

`after` のような、それの次の要素からを取得できる形です。 cursor ベースでしょうか。

3. **アカウント一覧**: `GET /accounts` は自分がオーナーのアカウントとメンバーのアカウント両方を返すか？

ログインユーザーが owner になっているものと、ログインユーザーが memberIds に含まれているものの一覧です。

4. **レポート期間指定**: レポート API のクエリパラメータは？（例: `?year=2024&month=1` / `?from=2024-01-01&to=2024-12-31`）

レポート機能は一度すべて削除してください。

5. **エクスポート範囲**: JSON エクスポートの対象は？（全期間のデータ？期間指定可能？）

月別です。

6. **ユーザー更新 API**: displayName 更新用のエンドポイントが必要（例: `PATCH /auth/me`）か？

user リソースを追加してください。

## データモデル・ロジック

7. **カテゴリの order**: 新規カテゴリ作成時の order の初期値は？並び替え機能の API は必要？

カテゴリ数 + 1 にしてください。

8. **Transaction 編集権限**: 作成者 (createdBy) 以外のメンバーも編集・削除可能か？

メンバーにも編集・削除は可能です。

## フロントエンド技術選定

9. **状態管理**: Redux / Zustand / React Query / その他、何を使用するか？

jotai を使用してください。

10. **UI ライブラリ**: Tailwind CSS / MUI / shadcn/ui / その他、何を使用するか？

tailwind を使用してください。

11. **グラフライブラリ**: Chart.js / Recharts / その他、何を使用するか？

グラフ表示はしません。もし docs/SPEC.md にその記述があるなら削除してください。
