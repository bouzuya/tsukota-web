# 078

- backend/crates/firestore-client の FirestoreClient に `google::firestore::v1::Write` を生成するためのメソッドを追加します
- 作成と更新と削除のそれぞれの操作を提供します
- 具体的には FirestoreClient::{build_create_write, build_delete_write, build_set_write, build_update_write} を追加してください
- create は current_document: Some(Precondition { condition_type: Some(ConditionType::Exists(false))}) で Operation::Update を指定
- delete は current_document: Some(Precondition { condition_type: Some(ConditionType::Exists(true))}) で Operation::Delete を指定
- update は current_document: Some(Precondition { condition_type: Some(ConditionType::Exists(true))}) で Operation::Update を指定
- set は current_document: None で Operation::Update を指定
- この計画に怪しい点・懸念点があれば指摘してください
