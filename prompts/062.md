# 062 - フロントエンド実装計画

## 概要

SPEC.md に基づき、React + Vite SPA アプリケーションを構築します。

## 現状

- Vite + React テンプレートが設定済み
- 依存関係インストール済み: react-router-dom, jotai, tailwindcss
- Tailwind CSS 設定済み

## 実装ステップ

### Step 1: 基盤整備

1. **型定義** (`api/types.ts`)
   - User, Account, Category, Transaction 型
   - API レスポンス型

2. **API クライアント** (`api/client.ts`)
   - fetch ラッパー
   - JWT 自動付与
   - 401 時のトークンリフレッシュ
   - RFC 9457 エラーハンドリング

3. **認証 API** (`api/auth.ts`)
   - `/auth/me`, `/auth/logout`, `/auth/refresh`

### Step 2: 状態管理

1. **認証 atom** (`atoms/auth.ts`)
   - currentUser atom
   - isAuthenticated atom

2. **アカウント atom** (`atoms/accounts.ts`)
   - accountsAtom (一覧)
   - selectedAccountAtom

3. **カテゴリ/取引 atom**
   - categoriesAtom
   - transactionsAtom

### Step 3: 共通コンポーネント

1. **レイアウト系**
   - Layout.tsx: ヘッダー + メインコンテンツ
   - Header.tsx: ロゴ、ユーザーメニュー
   - Navigation.tsx: アカウント選択後のナビ

2. **フォーム系**
   - Button, Input, Select
   - Modal (確認ダイアログ用)
   - LoadingSpinner

### Step 4: ルーティング設定

```tsx
// App.tsx
/                     → LoginPage (未認証) or DashboardPage (認証済み)
/login                → LoginPage
/accounts/:id         → TransactionListPage
/accounts/:id/new     → TransactionFormPage (新規)
/accounts/:id/edit/:txId → TransactionFormPage (編集)
/accounts/:id/categories → CategoryManagePage
/accounts/:id/settings   → AccountSettingsPage
/settings             → UserSettingsPage
```

### Step 5: 各画面実装

1. **ログイン画面** (`LoginPage.tsx`)
   - Google ログインボタン
   - `/auth/google` へリダイレクト

2. **ダッシュボード** (`DashboardPage.tsx`)
   - アカウント一覧表示
   - アカウント作成ボタン
   - アカウント選択でTransactionListPageへ

3. **収支一覧** (`TransactionListPage.tsx`)
   - 取引一覧 (日付降順)
   - カーソルベースページネーション
   - 取引タップで編集画面へ
   - 追加ボタン

4. **収支登録・編集** (`TransactionFormPage.tsx`)
   - 日付、金額、カテゴリ、コメント入力
   - 保存/キャンセル
   - 編集時: 削除ボタン

5. **カテゴリ管理** (`CategoryManagePage.tsx`)
   - カテゴリ一覧
   - 追加/編集/削除 (論理削除)

6. **アカウント設定** (`AccountSettingsPage.tsx`)
   - アカウント名編集
   - オーナー一覧表示
   - アカウント削除
   - JSONエクスポート (月選択)

7. **ユーザー設定** (`UserSettingsPage.tsx`)
   - 表示名編集
   - ログアウト

### Step 6: 最終調整

1. レスポンシブ対応確認
2. ローディング状態の統一
3. エラー表示の統一
