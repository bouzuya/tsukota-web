- frontend/ のサインインの動作を変更します
- サインイン画面では「はじめる」と「他のデバイスからの移行」の 2 つのボタンを表示してください
- 「はじめる」を押すと、 Device ID と Device Secret を自動生成するようにしてください
- 「他のデバイスからの移行」を押すと、従来通りの Device ID と Device Secret を入力できるようにしてください
- 加えて、アカウント設定画面で Device ID と Device Secret を確認できるようにしてください
- アカウント設定画面での Device Secret は既定値では隠しておき、ボタンを押してはじめて表示されるようにしてください
