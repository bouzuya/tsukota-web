# 052 - api crate 実装計画

## 概要

api crate は axum を使用した HTTP API レイヤーを提供します。application crate の use case を HTTP エンドポイントとして公開します。

## ディレクトリ構造

```
backend/crates/api/src/
├── lib.rs                    # モジュールエクスポート、Router 構築
├── error.rs                  # ApplicationError → HTTP レスポンス変換
├── extractor.rs              # カスタム Extractor (認証ユーザー取得など)
├── state.rs                  # AppState 定義 (use case の依存注入)
├── handler/
│   ├── mod.rs
│   ├── command.rs            # POST /commands/* ハンドラ
│   └── query.rs              # GET /accounts/* ハンドラ
└── router.rs                 # ルーティング定義
```

### 2. エラー変換 (error.rs)

ApplicationError を axum の IntoResponse として実装。RFC 9457 形式。

```rust
impl IntoResponse for ApiError {
    fn into_response(self) -> Response {
        let (status, error_type, detail) = match self.0 {
            ApplicationError::AccountNotFound => (
                StatusCode::NOT_FOUND,
                "account_not_found",
                "The specified account was not found",
            ),
            ApplicationError::Unauthorized => (
                StatusCode::FORBIDDEN,
                "unauthorized",
                "You do not have permission to access this resource",
            ),
            // ...
        };

        let body = json!({
            "type": error_type,
            "title": detail,
            "status": status.as_u16(),
        });

        (status, Json(body)).into_response()
    }
}
```

### 4. コマンドハンドラ (handler/command.rs)

```rust
// POST /commands/create_account
pub async fn create_account(
    State(state): State<Arc<AppState>>,
    AuthUser(user_id): AuthUser,
    Json(request): Json<CreateAccountRequest>,
) -> Result<(StatusCode, Json<CreateAccountResponse>), ApiError> {
    let response = state.create_account.execute(&user_id, request).await?;
    Ok((StatusCode::CREATED, Json(response)))
}

// POST /commands/update_account
pub async fn update_account(
    State(state): State<Arc<AppState>>,
    AuthUser(user_id): AuthUser,
    Json(request): Json<UpdateAccountRequest>,
) -> Result<StatusCode, ApiError> {
    state.update_account.execute(&user_id, request).await?;
    Ok(StatusCode::NO_CONTENT)
}
```

### 5. クエリハンドラ (handler/query.rs)

```rust
// GET /accounts
pub async fn list_accounts(
    State(state): State<Arc<AppState>>,
    AuthUser(user_id): AuthUser,
) -> Result<Json<Vec<AccountView>>, ApiError> {
    let accounts = state.list_accounts.execute(&user_id).await?;
    Ok(Json(accounts))
}

// GET /accounts/:id/transactions?after=xxx
pub async fn list_transactions(
    State(state): State<Arc<AppState>>,
    AuthUser(user_id): AuthUser,
    Path(account_id): Path<String>,
    Query(params): Query<ListTransactionsParams>,
) -> Result<Json<TransactionList>, ApiError> {
    let account_id = account_id.parse().map_err(|_| ApiError::InvalidRequest)?;
    let list = state.list_transactions.execute(&account_id, &user_id, params.after).await?;
    Ok(Json(list))
}
```

### 6. ルーター (router.rs)

```rust
pub fn create_router<S>(state: Arc<AppState>) -> Router {
    Router::new()
        // Commands
        .route("/commands/create_account", post(command::create_account))
        .route("/commands/update_account", post(command::update_account))
        .route("/commands/delete_account", post(command::delete_account))
        .route("/commands/add_owner", post(command::add_owner))
        .route("/commands/remove_owner", post(command::remove_owner))
        .route("/commands/add_category", post(command::add_category))
        .route("/commands/update_category", post(command::update_category))
        .route("/commands/delete_category", post(command::delete_category))
        .route("/commands/add_transaction", post(command::add_transaction))
        .route("/commands/update_transaction", post(command::update_transaction))
        .route("/commands/delete_transaction", post(command::delete_transaction))
        // Queries
        .route("/accounts", get(query::list_accounts))
        .route("/accounts/:id", get(query::get_account))
        .route("/accounts/:id/categories", get(query::list_categories))
        .route("/accounts/:id/transactions", get(query::list_transactions))
        .route("/accounts/:id/export/json", get(query::export_transactions))
        .with_state(state)
}
```

## 実装順序

### Phase 1: 基盤
1. Cargo.toml に依存関係を追加
2. error.rs - エラー変換
3. state.rs - AppState 定義
4. extractor.rs - AuthUser (モック実装)

### Phase 2: コマンドハンドラ
5. handler/command.rs - Account 関連コマンド
6. handler/command.rs - Category 関連コマンド
7. handler/command.rs - Transaction 関連コマンド

### Phase 3: クエリハンドラ
8. handler/query.rs - Account 関連クエリ
9. handler/query.rs - Category 関連クエリ
10. handler/query.rs - Transaction 関連クエリ

### Phase 4: 統合
11. router.rs - ルーティング定義
12. lib.rs - モジュールエクスポート

## スコープ外 (今回は実装しない)

- 認証エンドポイント (`/auth/*`) - Firebase Auth 連携が必要
- ユーザー管理 (`/users/*`, `/commands/update_user`) - User は Firebase Auth で管理
- CORS 設定 - フロントエンド実装時に追加
- ミドルウェア (トレーシング、リクエストログ) - 後で追加
