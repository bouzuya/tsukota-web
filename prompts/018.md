# 018

tsukota の account-events.ts と docs/SPEC.md の間の不一致:

## 1. カテゴリの order フィールド

**SPEC.md**:
- カテゴリに `order` フィールドがあり、表示順を管理
- 新規カテゴリの order: 既存カテゴリ数 + 1

**tsukota**:
- カテゴリに `order` フィールドは存在しない
- カテゴリの並び順は定義されていない

## 2. Transaction の created_by フィールド

**SPEC.md**:
- Transaction に `createdBy` (作成者のユーザー ID) フィールドがある
- 編集・削除権限: 作成者以外のメンバーも可能

**tsukota**:
- Transaction に作成者情報は含まれない
- TransactionProps は amount, categoryId, comment, date のみ

## 3. メンバー vs オーナー

**SPEC.md**:
- "メンバー" という用語を使用
- オーナーとメンバーの区別
- メンバーの招待・管理機能

**tsukota**:
- "オーナー" (owners) という用語を使用（複数形）
- 複数のオーナーが存在可能
- オーナーとメンバーの区別なし

## 4. Account の削除

**SPEC.md**:
- アカウント削除機能が明記されている
- オーナー権限でアカウント削除が可能

**tsukota**:
- AccountDeleted イベントが定義されている
- SPEC.md と一致（実装済み）

## 影響

これらの不一致は、以下のどちらかの対応が必要です：

1. SPEC.md を tsukota の仕様に合わせて更新する
2. tsukota-web で独自の拡張を行う（order, created_by フィールドの追加）

現在の実装は tsukota の仕様に準拠しています。


1 の docs/SPEC.md を tsukota の仕様に合わせて更新してください。
