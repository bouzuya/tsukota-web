# 109

- backend/ から frontend/ のファイルを配信できるようにします
- frontend/ で `vite build` したものを Docker image に埋め込む想定です
- backend/ の api crate から、指定したディレクトリのファイルを配信できるようにします
    - `vite build` したものは `public/` ディレクトリに配置します
    - `public/index.html` を `/` で配信し、 `public/assets/*` を `/assets/*` で配信します
- おそらく `vite build` の結果は `index.html` と `assets/*` だけだと思いますが、そうでないときはそうでなかったファイルを報告して対応を相談してください
